# زيتونة — بوابة المناهج والتدريس

بوابة Google Apps Script عربية RTL لإدارة البيانات الأساسية وتأسيس دورة الدروس داخل المدرسة. **MILESTONE = 3.0.0**

## الهندسة والملفات

تستخدم الطبقات خدمات مستقلة وGoogle Sheets كقاعدة بيانات: الإعداد والثوابت (01–02)، البنية التحتية (03–08)، الهوية والأدوار والملفات والنسخ والتهيئة والتشخيص (09–15)، المتحكم والتفويض (16–17)، ثم خدمات البيانات (18–22). ملفات HTML هي القشرة والمكونات والصفحات.

## المتطلبات

حساب Google Workspace، مشروع Apps Script مربوط بجدول بيانات، وGoogle Drive. لا توجد مكتبات خارجية. ملف `appsscript.json` يحدد V8 والنطاقات المطلوبة.

## التهيئة

اربط المشروع بجدول بيانات، ثم شغّل `initializeSystem()` من محرر Apps Script. العملية قابلة لإعادة التشغيل ولا تحذف أو تفرغ البيانات؛ تنشئ الجداول الناقصة فقط وتضيف إعداد الإصدار. أضف المستخدمين والأدوار والصلاحيات التقنية من جدول `USERS` و`ROLE_PERMISSIONS` وفق سياسة المدرسة.

## النشر

من Apps Script اختر **Deploy > New deployment > Web app**، نفّذ باسم المستخدم الذي يصل للتطبيق، واجعل الوصول لمستخدمي النطاق. استخدم عنوان النشر للوصول إلى `doGet()`.

## المنفذ في Milestone 3

قشرة عربية RTL، تعريف مستخدم Workspace، غلاف API موحد `{success,data,message,errorCode}`، تفويض خادمي، لوحة تأسيسية، عرض/بحث البيانات الأساسية، وأساس الدروس مع الحالات المحددة، والتدقيق للأحداث الأساسية، وسجل النظام للأخطاء، ومجلدات Drive الأساسية وواجهات القوالب.

## المؤجل والقيود

لم تُنفذ بعد دورة إعداد محتوى الدرس الكاملة، التقييمات، محرك التقارير، الإشعارات، والتزامن المتقدم. يلزم ضبط صلاحيات المؤسسة وإضافة مستخدميها قبل التشغيل؛ لا تُنشئ التهيئة طلاباً أو معلمين أو سجلات أعمال وهمية.

## نقطة بدء Milestone 4

ابدأ بتثبيت نموذج محتوى الدرس والقوالب، ثم سير المراجعة والتقييمات. حافظ على المعرفات الثابتة، الحالات المركزية، التفويض الخادمي، السجل التدقيقي، وعدم الحذف التدميري أو تخزين بيانات حساسة في الواجهة.
